# Document Reader — نسخه اصلاح‌شده امنیتی

ابتدا SECURITY-REVIEW-FA.md و سپس backend/deployment/README-DEPLOYMENT-FA.md را بخوانید.

- backend: سورس کامل بک‌اند اصلاح‌شده و تنظیمات نمونه استقرار
- client/apiClient.js: فایل هماهنگ جدید کلاینت؛ قرارداد احراز هویت و URL صوت تغییر کرده است
- tests: تست‌های بک‌اند با EF InMemory و Provider شبیه‌سازی‌شده
- client/test-*.mjs: آزمون‌های کلاینت
- test-results: نتایج آزمون‌ها و اسکن وابستگی‌ها

دو مورد عمداً دست‌نخورده: اتمیک‌سازی OTP و تغییر معماری پردازش خارجی اسناد.

این بسته شامل رازهای عملیاتی، فایل باینری استقرار یا نصب خودکار روی سرور نیست. برای استقرار، مقادیر واقعی را از مسیر امن تنظیم و بیلد کنید؛ سپس Staging و زیرساخت را تست کنید.
